# 原生兼容性与维护边界

当前仅 Linux x64。

Hook 位于 FireBullet 专用命中过滤辅助函数的 BuildOutput 后续位置，使用 MidHookContext.r15 读取trace对象。代码中历史版本注释为CS2 Linux1.41.7.8；游戏更新后应重新核对签名、寄存器上下文与结构布局。

| 字段 | 偏移/大小 |
|---|---|
| 表面数 / 表面数组 | 0x00 / 0x08 |
| 命中数 / 命中数组 / 容量 | 0x1C20 / 0x1C28 / 0x1C30 |
| 命中元素大小 | 0x18 |
| 命中起始表面 / 结束表面 | 0x10 / 0x12 |
| 表面大小 / 实体句柄 | 0x38 / 0x2C |
| 表面索引掩码与无效索引 | 0x7FFF |
| 最大命中数 / 最大表面数 | 1024 / 4096 |

## 更新检查

1. 确認目标是游戏逻辑的server库，不是同名的框架加载垫片。
2. 在未安装本Hook的位置扫描签名，并要求唯一匹配；安装后签名会被跳转改写，不应再用原签名重复定位。
3. 对目标版本反汇编，核实函数语义、r15对象、数组布局与后续穿透处理；不能只凭44字节匹配就认定兼容。
4. 记录核对过的游戏版本和server库SHA256，维护准确的版本说明。

## 安全限制

- 指针数值处于常见用户地址范围，并不证明内存已映射或布局正确。
- try/catch只能用于托管异常隔离，不能承诺捕获任意原生访问异常。
- 尽管实现继承了卸载失败时保持inactive状态并记录严重日志的处理，但不能据此证明框架ALC卸载与原生回调地址仍然安全。若卸载失败，应停止进一步热重载并在维护窗口重启进程排查。
- 这些检查不是“热重载绝对安全”或“跨游戏版本通用”的保证。
- 当前同时保留主项目内置版本，不允许与独立版同时启用。签名失配可能意味着版本变化，也可能表示另一个Hook已占用位置；不要强行覆盖。
